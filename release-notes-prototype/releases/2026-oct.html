Platform Patch Updates

Date Component Version Updates
Sept 10, 2026 Snaplex 4.45.0.2_war-45775 (Recommended) Fixed a Snaplex issue where a newly started JCC node would immediately check for active FeedMaster nodes before any status had been received, causing Ultra Tasks to be incorrectly blocked with No Active Feed Masters found errors — even when the FeedMaster nodes were healthy and available.
Fixed an issue where memory utilization across all Cloudplex nodes increased after upgrading to 4.45.

Admin Manager

New features

  • SnapGPT Standards tab: Environment admins can now publish Markdown-based standards to control how SnapGPT generates or refines pipelines. SnapGPT automatically enforces Always standards for all users. Users can enable Optional standards for each session from the SnapGPT panel. Learn more.
