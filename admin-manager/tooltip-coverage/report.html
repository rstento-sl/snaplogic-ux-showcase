Icon mismatch

Design system gap

Admin Manager's tooltip trigger doesn't use the current icon set. The tooltip mechanism itself (Jellyroll/components/Tooltip) is the correct Design System 2.0 component, but every place that pairs it with an icon reuses a legacy asset — SL_UI/v3/icons/info2.svg, a solid gray-filled circle — instead of jellyroll's own CircleInfo or info icon from the jellyroll Icon set. jellyroll-ui doesn't export a ready-made InfoTooltip component, so each page pairs the icon and the tooltip by hand, and every instance made the same outdated choice.

Fix: swap the <img src={InfoIcon}> in the three existing tooltip usages for jellyroll's CircleInfo icon, and use that pairing as the template for the missing tooltips below rather than reintroducing info2.svg.

Fields with no tooltip at all

The shared Tooltip component is used in only three places in the whole Admin Manager module. Everywhere else, labeled fields ship with no tooltip — including several non-obvious SSO security settings that would benefit most.

Groups — create / details

FieldNote
Group nameOnly a static note string, no tooltip
DescriptionNo tooltip
Add usersNo tooltip

Users — account form

FieldNote
First name / Last name / EmailNo tooltip
Role — Env Admin / User / Portal UserNone of the three options explains what it grants
App access checkboxes, API accessNo tooltip on any app or on API access
Home directory toggleNo tooltip
Enable password login / Enable MFA loginNo tooltip

SSO configuration

FieldNote
Upload IdP file, SAML link fieldsStatic descriptive paragraphs only, no tooltip
AuthnRequestsSignedNo tooltip on this SAML security setting
RequestedAuthnContext comparisonNo tooltip on this SAML security setting
AuthnContextClassRefNo tooltip on this SAML security setting

These three SAML options are the strongest candidates for a fix: they're technical, non-obvious settings with no inline help at all. One nearby control (the copy-URL button in link.js) uses a plain HTML title attribute instead of the shared component — an inconsistent pattern worth fixing at the same time.
