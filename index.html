UX issue showcase

Confusing UI interactions and microcopy across the SnapLogic Admin UI, with proposed fixes — for PM and engineering review.

Each linked page shows the real screen on the left and a proposed redesign on the right. Click a red pin on the left to see what's confusing; click the matching green pin on the right to see the suggested fix.

Some pages also flag an In-app UA opportunity — a place where in-app user assistance (UA), delivered by a tool like Userpilot or Appcues, could work better than static page text. A short guided walkthrough can explain a multi-step or easily-confused setting more clearly than a dense note or a tooltip, without adding permanent clutter to the page.

Existing tooltips only appear after hovering a field for a second or two, so they're easy to miss entirely. Several proposed redesigns add a visible tooltip icon next to the field label instead, so it's discoverable at a glance — see the Add/Update Snaplex dialog for the clearest example.
