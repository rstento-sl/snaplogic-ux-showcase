Allow nullable for last modified date
Enabling "Allow nullable for last modified date" permits the selection of a nullable column for audit tracking. When enabled, the system allows null values in the last modified timestamp, ensuring flexibility for records that do not require mandatory updates. This option supports use cases where modification timestamps may not always be available or applicable.
