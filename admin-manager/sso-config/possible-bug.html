Why is this button disabled?

“Download file” is an alternate way to provide SnapLogic metadata to your IdP — instead of copying the individual Entity ID, Reply URL, and Logout URL. It shouldn't only become enabled after users upload their SSO configuration first.
Suggested next step
File as an engineering bug, separate from the SSO UX catalog (APP-2297). Ask engineering to confirm whether the disabled state is intentional and, if so, what the actual dependency is.
