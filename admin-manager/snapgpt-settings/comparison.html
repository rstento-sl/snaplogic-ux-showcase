SnapGPT

Select the SnapGPT settings that best fit your users' workflow. Credentials are never sent to SnapGPT regardless of which settings are enabled. Learn more

i New to SnapGPT? Read the SnapGPT overview.
2
Enable SnapGPT
Controls user access to SnapGPT for everyone.
Use schemas when generating SQL queries
SnapGPT generates more accurate queries using the schema. When disabled, generated queries might require edits.
Use preview data schema
Preview data schemas give SnapGPT access to field names and data types.
Describe pipeline
Generates a pipeline description from metadata without accessing credentials. When disabled, the Describe pipeline option isn't available.
3
Use preview data for contextual metadata
Provides insights into key fields, business and validation rules, and Personally Identifiable Information (PII).
4
Use pipelines for enhanced generation

Sets how SnapGPT uses existing pipelines as examples for Retrieval Augmented Generation (RAG): selected automatically (Auto), selected manually by users (Manual), or turned off (Disable). This sets the environment default — users can choose a more restrictive option in their personal settings.
